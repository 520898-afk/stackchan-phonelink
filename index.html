设置小智 MCP 接入点

在 xiaozhi.me 控制台 → 智能体 → MCP 接入点，复制 wss://api.xiaozhi.me/mcp/?token=… 整行粘贴到这里。

⚠️ 这个 token 等于你小智智能体的工具接入权限。它只保存在这台手机的浏览器本地存储里，不会上传到托管网页的服务器；但任何能打开这台手机这个网页的人都能看到/使用它。不要截图外发；泄露后请到小智控制台重置接入点。取消“记住”则关闭页面后需重新粘贴。

怎么用 / 限制
  • 对小智说「打开淘宝」「在抖音搜猫咪」「B站搜钢琴」。
  • 本页必须开着并在前台：锁屏、切到别的 App 后，iOS 会暂停网页、断开连接；回到本页会自动重连。
  • Safari 打开别的 App 时可能弹出「在“淘宝”中打开？」需点“打开”；若没有自动跳转，点绿色大按钮即可。
  • 建议 Safari → 分享 → 添加到主屏幕，从主屏幕图标启动。
  • 白名单：。不能付款、转账或打开任意网址。
